# 🎮 AWTQuest: An Interactive ASP.NET Learning Platform

[![Live Demo](https://img.shields.io/badge/Play_Now-Live_Demo-success?style=for-the-badge)](http://awtquest.somee.com)

AWTQuest is a gamified, interactive educational web application built to teach and test advanced ASP.NET concepts. From foundational Web Forms architecture to Post-Graduate level CI/CD pipelines and MVC routing, this platform transforms standard studying into a hands-on arcade experience.

## 🚀 Live Project
**Play the game here:** http://www.awtquest.somee.com](http://www.awtquest.somee.com)
*(Note: As this is hosted on a free tier, the initial load may take 10-15 seconds as the server wakes up).*

## 🌟 Key Features
* **📚 The Library:** Comprehensive study modules covering ASP.NET architecture, State Management, LINQ, WCF, and MVC.
* **🧩 The Grand Arcade (Dynamic Minigames):**
  * **Memory Matchers:** Interactive matching games scaling from Undergrad terminology to Enterprise System Architecture.
  * **The Pipeline Hacker:** A sequence puzzle requiring users to chronologically order the MVC Request Pipeline and CI/CD deployment stages.
* **🕵️‍♂️ Code Cracker:** A debugging simulator using `MultiView` where users must identify missing C# syntax and ASP.NET control attributes.
* **🔐 The Decryptor:** A JavaScript-powered tech-hangman game testing framework vocabulary.
* **⚔️ The Final Boss:** A 20-question comprehensive quiz.
* **🏆 Global Leaderboard:** Tracks and ranks total accumulated XP using global Application State management.

## 💻 Tech Stack
* **Backend:** C#, ASP.NET Web Forms (.NET Framework 4.8)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **State Management:** `Session` (User Tracking) and `Application` (Global Leaderboard)
* **Hosting / Deployment:** IIS Windows Server 2022 (Deployed via Somee)
